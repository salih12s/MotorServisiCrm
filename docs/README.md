# Ürün Görselleri

Bu klasör, Demirkan Motorlu Araçlar platformunun README ürün turunda kullanılan
ekran görüntülerini içerir.

| Grup | İçerik |
|---|---|
| `public-*` | Dijital vitrin, katalog, ürün detayı, fiyat listesi ve sepet |
| `panel-*` | Servis, satış, stok, raporlama, kullanıcı ve SMS ekranları |
| `mobil-*` | Public site ve operasyon panelinin mobil görünümleri |
| `login.jpg` | Kullanıcı giriş ve kayıt deneyimi |

Görseller izole bir demo veritabanında, tamamen kurgusal kayıtlarla oluşturulmuştur.
Canlı veritabanı veya gerçek kullanıcı bilgisi kullanılmamıştır.
